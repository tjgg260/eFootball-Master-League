# App audit — what's broken, half-built, or clunky (2026-09-17)

## Context

You asked which systems don't work as they should, aren't properly built out, or could feel
better. Three read-only sweeps were run — every screen, every game system, and the data + Play
Match pipeline against the real `build/game_world.db` — and I re-checked the worst claims by hand
(code reads + read-only queries). Nothing was changed. Items marked ✔ I verified myself; the rest
come from the sweeps with file references. Below: the audit, then the order I'd fix things in.
Approving this plan = start on Batch 1.

**The honest headline:** the management side is deep and mostly real (board, staff, scouting,
academy, training, negotiation, news, history, backups all work). The weak points are (1) a few
things that are flat-out broken on the new game-built world, (2) the link back INTO the match —
your players' development, tiredness, injuries and bans don't reach eFootball, (3) two of your own
rulings (half-stars, ⋯ buttons) never got rolled out, and (4) release blockers.
